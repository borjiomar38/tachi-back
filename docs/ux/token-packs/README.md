# Nayovi token packs — desktop proposal

Visual target: [token-packs-desktop-mockup.png](token-packs-desktop-mockup.png).

The user approved local implementation. Production remains explicitly blocked pending separate validation. See [implementation and validation](implementation-validation.md).

The shared decisions, code-review findings, final generation prompts and mobile reference are in [the token-pack proposal](../../../../TachiyomiAT/docs/ux/token-balance/token-packs-proposal.md).

Three one-time packs: 250 tokens / USD 2.00; 1,250 tokens / USD 10.00; 2,750 tokens / USD 20.00. No chapter-count equivalents and no fixed translation-cost claim. Translation cost varies by mode. The latest user decision supersedes the mockup's “cost before starting” sentence: translating starts directly, with no cost or download confirmation modal. The server controls billing. The planned Translate Pro mode is not priced or announced here.

The mockup was created with built-in ImageGen, using the inspected real web pricing screenshot and the corrected, approved-style mobile modal as references. Output inspected for copy, quantities, prices and purple/gold style.
